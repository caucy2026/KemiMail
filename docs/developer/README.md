# Developer Documentation

Developer focused documentation for contributing to the codebase. It's dedicated to providing essential guides,
checklists, and architectural notes to help you navigate the codebase and contribute safely.

## Checklists

Detailed checklists to ensure best practices and consistency across the codebase:

- **[Database Migration Checklist](./db-migration-checklist.md)**
  A mandatory checklist for creating and reviewing database migrations to ensure they are safe, performant, and correct.

## Device-specific UI guides

- **[KEMI Mail Build, Installation, and Acceptance Guide](./kemi-build-install-guide.md)**
  Detailed instructions for building KEMI APK variants, installing Debug builds on dual-screen tablets, validating
  signatures and versions, and troubleshooting common build and ADB failures.
- **[KEMI Dual-screen UI Projection and Troubleshooting Guide](./kemi-dual-screen-ui-guide.md)**
  Architecture, implementation rules, audit steps, and device verification for keeping KEMI activities and transient
  UI in one continuous dual-screen workspace.

## Service operations

- **[KEMI Credential Relay Deployment and Troubleshooting Runbook](./kemi-credential-relay-runbook.md)**
  Architecture, deployment boundaries, health checks, protocol verification, recovery steps, and Android-side
  troubleshooting for the encrypted credential relay.
